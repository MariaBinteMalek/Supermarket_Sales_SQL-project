# Supermarket Sales Data Analysis — SQL Project

### Project Overview

This project analyzes a supermarket sales dataset using SQL to identify sales patterns, customer behavior, product performance, payment preferences, and city-wise business performance.



The project demonstrates practical SQL skills through business-focused queries and data analysis.



## **Dataset**

The dataset contains 1,000 supermarket sales transactions with information about:



* Invoice ID



* Branch



* City



* Customer type



* Gender



* Product line



* Unit price



* Quantity



* Tax5%



* Total



* Date



* Time



* Payment



* cogs



* gross margin percentage



* gross income



* Rating



* Month

The main objectives of this project are to:

#### \## Key Business Insights







The SQL analysis provided the following business insights:







\* Naypyitaw recorded the highest sales among the three cities.



\* Product line performance varied across the different product categories.



\* Member and Normal customers showed differences in sales and transaction behavior.



\* Sales performance varied across gender groups and payment methods.



\* City and product line comparisons helped identify differences in product performance across locations.



\* Advanced SQL analysis using Running Total, LAG, and LEAD helped examine sales trends and compare sales across transactions.
